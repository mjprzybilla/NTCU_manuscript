# MD6812 Right Lung

**MD6812__static_tree.png** - Phylogenetic tree with sensitivity corrected branch lengths in png format. 

**MD6812_Right_Lung_sensitivity_adjusted_filtered.pdf** - Phylogenetic tree with sensitivity corrected branch lengths in pdf format. 

**cluster_and_samples.csv** - Table showing the results from NDP clustering approach for the respective lung.

**MD6812__SigFit_annotated.png** - Phylogenetic tree with sensitivity corrected branch lengths and annotated signatures per clone in png format. 

**MD6812_img.png** - Histological images containing all regions for which LCM microbiopsies were dissected. 

**MD6812_Right_Lung_branch_lengths.csv** - Table containing branch lengths per clone. 

**MD6812_Right_Lung_loc_tbl.csv** - Table containing the annotated location of each LCM microbiopsy in the histological image *MD6812_img.png*.

**MD6812_Right_Lung_ndp_assigned_muts_final.csv** - Table containing all mutations detected across each microbiopsy and their assignment to clones detected in the NDP clustering.

**MD6812_Right_Lung.cluster_tree.phylo** - Phylogenetic tree object for the respective lung. 

**MD6812_Right_Lung.edge_tbl.csv** - Table representing phylogenetic tree for the respective lung
